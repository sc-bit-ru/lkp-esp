# Политика конфиденциальности расширения «ЛК ЕСП → CRM»

Расширение ставит сам пользователь. Оно работает только с теми двумя адресами, которые он сохранил в настройках и которые разрешил Chrome.

## Какие данные обрабатываются

Пока пользователь смотрит страницы кабинета, расширение копирует JSON-ответы, которые эта страница уже запросила. Копия содержит адрес запроса, метод, код ответа, адрес страницы и тело ответа.

На приём уходят только удачные ответы (`2xx`) с домена кабинета и только по списку путей приёма. Это данные кабинета о клиентах, кассах, блоке ЕСМ и заявках, включая email и телефон, если они есть в карточке заявки.

Не копируются и не отправляются: пароль кабинета, cookie, заголовок `Authorization` страницы, тела адресов `/auth/`, поля `accessToken` и `refreshToken`.

Токен приёма пользователь вводит сам. Он хранится локально в браузере (`chrome.storage.local`) и уходит только заголовком `Authorization: Bearer` на адрес приёма из настроек.

## Куда уходят данные

Только на https-адрес приёма, который пользователь указал в настройках. Другим адресам расширение данные не отправляет.

Расширение не продаёт данные, не показывает рекламу и не передаёт их другим сервисам.

Если приём недоступен, копия остаётся в локальной очереди браузера до следующей попытки. Повторный запрос в кабинет из-за этого не делается.

## Хранение

Домен кабинета, адрес приёма, токен, очередь снимков и короткий журнал ошибок хранятся на компьютере пользователя. Удаление токена стирает токен. Удаление расширения стирает локальные данные Chrome этого расширения.

## Запрос

По вопросам данных напишите администратору, который выдал токен приёма.
